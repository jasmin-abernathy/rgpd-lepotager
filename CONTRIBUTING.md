# Contribuer

Les contributions sont bienvenues sur le comparateur, le crawler, l’accessibilité, la documentation et les tests.

Avant de proposer une modification :

- ne commitez jamais de secrets, identifiants, exports de production ou données personnelles ;
- conservez les données runtime et observations privées hors Git ;
- documentez les sources utilisées et leur statut ;
- n’inventez pas de prix, de conformité, de partenariat ou d’information sur un prestataire ;
- gardez les traitements déterministes et explicables ;
- vérifiez les scripts PHP concernés avant envoi.

Les vulnérabilités doivent être signalées en privé selon `SECURITY.md`.

Les contributions sont placées sous AGPL-3.0-only.
