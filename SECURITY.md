# Politique de sécurité

## Versions suivies

La branche `main` est la seule branche suivie pour les correctifs de sécurité tant que le projet reste en développement actif.

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité présumée dans une issue publique.

Envoyez un signalement privé à `contact@lepotager.org` avec l’objet `Sécurité — Comparateur RGPD`. Indiquez le commit concerné, les étapes de reproduction, l’impact estimé et, si possible, une piste de correction.

N’envoyez pas d’identifiants réels, de données personnelles, d’exports de production ni de fichiers privés du crawler. Utilisez des exemples synthétiques.

Une attention particulière doit être portée aux formulaires, imports, tâches cron, données collectées, fichiers privés et limites anti-abus.
